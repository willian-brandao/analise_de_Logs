Coletar logs é único primeiro passo. Analistas de seguranaça devem ser capazes de acessar, pesquisar e visualizar dados de logs rapidamente e efetivamente para responder à incidentes ou realizar investigações. Escolher as ferraments corretas para acessar logs depende de fatores como formato de logs, origem, volume e fluxo de trabalho do time. 

## Ferramentas de Acesso Local

Em ambientes sem registros de logs centralizado, logs são acessados diretamente dos sistemas que eles são gerados. Isso é comum em investigação de endpoints, cenários de respostas à incidentes ou quando SIEMs não estão disponíveis. 

### Ferramentas de linha de comando ( Linux e Mac Os)

*  cat ( visualizar o conteúd das linhas de log)
*  less ( cria uma paginação iterativa para os registros de logs)
*  tail -f (mostra os logs em tempo real)
*  grep - (pesquisa por padrões em logs)
*   awk, sed - (filtra e formata a saída)
*   journalctl - (consulta os registros do systemd)
*   jq - (analisa registros de logs em JSON)

#### Exemplos

Visualizar as últimas tentativas falhas de login SSH:
```
grep "Failed password"  /var/log/auth.log/ | tail -n 20
```

Mostrar os logs de update do sistema 
```
tail -f /var/log/syslog
```

Analisar e formatar logs JSON vindos do Suricata:
```
cat eve.json | jq '.'
```

Consultar um período de tempo específico com o journalctl:
```
journalctl --since "2025-06-30 14:00:00" --until "2025-06-30 14:10:00"
```

### Ferramentas de Acesso Windows

1. Event Viewer - Interface gráfica para navegar por registros de logs.
2. Prompt do Powershell
   - *Get-EventLog* (legado)
   - *Get-WinEvent* (moderno, suporta consultas XML)
3. LogParser - Consulta logs EVTX usando SQL-like systax
4. Ferramentas Systernals - Para monitoramento em tempo real ( PsLogList, Procmon)

*Exemplos*

Pesquisar os últimos 10 eventos de segurança:
```
Get-WinEvent -logName Security -MaxEvents 10
```
Filtrar por id do evento:
```
Get-WinEvent -FilterhashTable @{LogName='Security'; Id=4625}
```

## Gerenciamento de Logs Centralizado e Plataformas de SIEM

Quando logs são coletados através de múltiplos sistemas, as plataformas centralizadas provêm recursos escaláveis de pesquisa e análise:

### Ferramentas populares:

1. Splunk
   - Pesquisa por logs usando SPL(Search Processing Language);
   - Dashboards, alertas e playbooks;
   - Usado em SOCs para triagem e resposta.
2. Elastic Stack
   - Elasticsearch, Logstash, Kibana;
   - Pesquisa e Visualização escaláveis;
   - Comum em implementações open-source.
3. Graylog
   - Registro de logs centralizado com alertas baseados em stream;
   - Suporta GELF e registro estruturado de logs.
   - Pipelines customizáveis.
4. Ferramentas de SIEM como Serviço
   - Microsoft Sentinel, Chronicle, QRadar Cloud
   - Ingestão escalável, regras correlacionadas, e alertas baseados em Machine learning.

#### Pesquisa básica com Splunk

Encontrar falhas de logins em todos os dispositivos windows:
```
index=Windows EventCode=4625 | stats count by Account_Name, host
```
Pesquisar por uso do Powershell com comandos codificados:
```
index=Windows "powershell" "EncodedComand"
```
#### Consulta do Elastic com Kibana

Filtrar todos os alertas vindo do Suricata com severidade 1:
```
{
  "query": {
    "bool": {
      "must": [
        { "match": { "alert.severity": "1" } },
        { "match": { "event_type": "alert" } }
      ]
    }
  }
}

```

## Caso de Uso para Visualização 

* Crie painéis para rastrear atividades de login, geolocalização de IPs e execução de comandos;
* Visualize picos em tentativas de login malsucedidas para detectar ataques de força bruta;
* Crie limites de alerta e linhas do tempo da atividade de incidentes;
* Use mapas de correlação para conectar eventos em diferentes hosts ou redes.

## Melhores práticas para acesso a logs pela equipe de segurança

* Crie e mantenha consultas salvas para cenários de ameaças comuns;
* Use extração e análise de campos no início do pipeline;
* Implemente acesso baseado em funções a logs confidenciais;
* Audite regularmente a visibilidade dos logs para garantir a cobertura em todos os sistemas;
* Personalize as visualizações para destacar anomalias, não apenas o volume bruto.
