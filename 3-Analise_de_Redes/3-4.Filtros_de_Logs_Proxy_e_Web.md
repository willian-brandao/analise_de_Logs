## Introdução 

Proxies e soluções de filtros web são componentes críticos no controle e no monitoramento de tráfico de saída para internet. Eles agem como intermediário entre usuários internos e recursos externos, permitindo que organizações reforcem suas políticas de segurança, bloqueiem conteúdo malicioso e registrem todos os logs de tentativas de acesso a web. 

A análise de logs de proxy e web filter da ao time de segurança insights dentro do comportamento do usuário, potenciais comunicações de malware, exfiltração de dados e tentativa de acesso de phishing. 

Ferramentas comuns que geram logs de proxy incluem:

* Squid Proxy.
* Blue Coat(Symantec ProxySG).
* Palo Alto URL Filtering.
* Cisco Umbrella.
* FortiProxy.
* Zscaler.

Campos Chave no Logs de Proxy 

Campos comuns em logs de proxy e filtros web:

|     Campo           |             Descrição                                 |
|---------------------|-------------------------------------------------------|
|   Timestamp         | Tempo de requisição                                   |
|   Source IP/User    | Cliente que inicia a requisição                       |
|   URL/URI           | Requisição de URL completa                            |
|   Domain            | Nome do host/domínio extraído da URL                  |
|   Método HTTP       | GET, POST, HEAD, etc                                  |
|   Response Code     | Resposta HTTP (200, 302, 403, etc)                    |
|   Action Taken      | Permitido, Bloqueado, Aviso                           |
|   Category          | Assinatura de categoria (ex: "Malware")               |
| Bytes Sent/Received | Frequentemente usado para detectar scanners e scripts |

## Exemplo: Registro de proxy Squid
```
1688130123.456  200 192.168.1.50 TCP_MISS/200 3456 GET http://malicious-site.com/ - HIER_DIRECT/203.0.113.10 text/html

```
Explicação:
* timestamp: UNIX epoch
* Tempo corrido: 200ms
* IP do cliente: 192.168.1.50
* Action/code: TCP_MISS/200 = request não armazenada em cache, reposta 200 ok
* Bytes: 3456
* Método/URL: HTTP GET para malicius-site.com

Exemplo: Registro do Web Filter Zscaler (CSV)
```
timestamp,src_ip,url,domain,http_method,response_code,action,category,user_agent
2025-06-30T15:24:10Z,10.0.0.15,http://evil-server.com/c2/checkin.php,evil-server.com,POST,200,Allowed,Command and Control,Mozilla/5.0
```

Red Flags:
* Método POST para o domínio C2.
* Ação é "Allowed".
* Categoria é "Command and Control".
