## Introdução 

Sistemas de Detecção de Intrusão (IDS) e Sistemas de Prevenção de Intrusão (IPS) são componentes chave nas camadas de estratégia de defesa. Enquanto firewalls focam no controle de tráfego, soluções de IDS/IPS analisam o contexto de tráfego e padrões para ameaças conhecidas ou desconhecidas. 

**IDS**: Detectar e alertar atividade suspeitas porém não as bloqueiam. 
**IPS**: Bloqueia ativamente ou interrompe tráfego malicioso baseado na lógica de detecção. 

Ferramentas IDS/IPS open-source:
* Snort(Cisco): Detecção baseada em assinatura.
* Suricata (OISF): Motor Multithread com capacidade IDS/IPS/NSM.
* Zeek: Monitoramento de segurança, não focado em assinaturas.

---

## Entendendo Logs IDS/IPS 

Logs de sistemas IPS/IDS usualmente incluem:

* Timestamp: quando o evento ocorreu.
* Signature ID: regra que gera o alerta.
* Source/Destination IP and Ports: IPs de origem e destino, portas de origem e destino.
* Protocol and packets details: detalhes dos protocolos usados para uma determinada atividade maliciosa.
* Message/Classification: Pequena descrição da ameaça.
* Severity/Priority: Severidade da atividade maliciosa.

---

## Exemplo: Log de Alerta do Snort 
```
[**] [1:1000001:1] ET SCAN Nmap Scripting Engine User-Agent Detected [**]
[Classification: Attempted Information Leak] [Priority: 2]
06/30-14:22:10.123456 192.168.1.100:58000 -> 10.0.0.20:80
TCP TTL:64 TOS:0x0 ID:1111 IpLen:20 DgmLen:48
***A**** Seq: 0x0  Ack: 0x0  Win: 0x400  TcpLen: 20
```
**Explanação:**
* SID: 1000001 - regra ou de ameaças emergentes.
* Classification - Tentativa de vazamento de informações.
* Traffic: Vindo de sistemas internos para servidor web na porta 80.
* User-Agent detection: Possivelmente um escaneamento de Nmap com script NSE.

## Exemplo: Log de Suricata Even Json (ingestão no SIEM)
``
{
  "timestamp": "2025-06-30T14:22:10.123456Z",
  "event_type": "alert",
  "src_ip": "192.168.1.100",
  "src_port": 58000,
  "dest_ip": "10.0.0.20",
  "dest_port": 80,
  "proto": "TCP",
  "alert": {
    "action": "allowed",
    "gid": 1,
    "signature_id": 2100498,
    "rev": 3,
    "signature": "ET SCAN Nmap Scripting Engine User-Agent Detected",
    "category": "Attempted Information Leak",
    "severity": 2
  }
}

``
### Benefícios do JSON Suricata:
* Fácil ingestão dentro de ferramentas SIEM.
* Formato estruturado para correlação.
* Habilitar dashboards e alertas com alta precisão.

## Casos de Usos para Analistas de Segurança

1. Detecção de Reconhecimento
   * Regra gerada por use-agent incomum, dns mal-formado, ou smb probes.
   * Exemplos de Suricata/Snort:
      * Detecção de Nmap.
      * Assinaturas de Masscan.
      * Tentativa de tunelamento DNS.
2. Tentativa de exploração
   * Kits de exploração, padrão de estouro de buffer, detecção de shellcode.
