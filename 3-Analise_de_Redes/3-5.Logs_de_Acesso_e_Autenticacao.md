## Introdução

Logs de acesso e autenticação são fundamentais para rastrear atividades, identificar anomalias e detectar potenciais incidentes de segurança como ataques de força bruta, roubo de credenciais, movimento lateral e escalonamento de privilégio. Esses logs servem como o fundamento para trilhas de auditorias, monitoramento de compliance, e identificação centralizada de detecção de ameaças.

* Logs de Segurança do Windows.
* Linux /var/log/auth.log.
* Controles de domínio do AD.
* Gateways de VPN.
* Plataformas de SSO (Okta, Azure AD, Keycloak).
* Logs do Cloud IAM (AWS CloudTrail, GCP Audit,Logs do Azure Sign-in).
* Web Application e APIs com autenticação de endpoints.

 ---

## Campos Chave em Logs de Autenticação 

|             Campo              |              Descrição                                  |
|--------------------------------|---------------------------------------------------------|
| Timestamp                      | Data e tempo do evento de login                         |
| Username                       | Conta usada durante a autenticação                      |
| IP origem                      | Origin da tentativa de login                            |   
| Host de destino                | Sistema ou serviço que está sendo acessado              |
| Tipo de autenticação           | Senha, MFA, Certificado, Kerberos, NTLM                 |
| Saída do Evento                | Sucesso, Falha, Bloqueio                                |
| Id de Evento / code            | Identificar plataformas específicas                     |
| Tipo de login                  | Interativo, Rede, RDP, Batch                            |
| Id de Sessão                   | Correlacionar eventos relacionados dentro de uma sessão |
| Reação da Falha                | Credenciais inválidas, contas desativadas, etc          |

```
An account was successfully logged on.

Subject: 
  Security ID: S-1-5-18
  Account Name: WIN-DC$
  Logon ID: 0x3E7

Logon Type: 10 (RemoteInteractive)
New Logon:
  Account Name: jsmith
  Logon GUID: {e2f...}
Network Information:
  Workstation Name: WIN10-PC
  Source Network Address: 192.168.1.10

```
### Event id 4625 - Login Falho
```
An account failed to log on.

Failure Reason: Unknown user name or bad password
Account For Which Logon Failed:
  Account Name: admin
  Workstation Name: WIN10-PC
Source Network Address: 203.0.113.55

```
